# Визуальная система слайдов

Правила вёрстки постов и каруселей YasenBrand! для Instagram. Подтверждены в октябре 2026.
Исходный Figma-файл с закрепами: https://www.figma.com/design/HIjCUfOWgS2XLst4sE3j9K/YasenBrand-

## Холст и типографика

- Формат поста: **1080×1350**. Сторис: **1080×1920**.
- Шрифт: **Manrope**.
- Поля: **100**. Текстовые блоки строго на **x = 100**.
- Фон: **белый или фиолетовый** — по смыслу содержания.
- Фирменный цвет: **#9900CC** + белый.
- Обложки и фоны — только Figma, ничего из Canva.
- Шрифты на слайдах сейчас мелковаты — увеличение обсуждается.

## Текст

- Один смысл на слайд, **до 35 слов**.
- Закрепы 1 и 3 под этот лимит придётся переработать.

## Фирменная графика

Три элемента: **логотип**, **знак-стрелка**, **решётка стрелок**.

### Знак-стрелка

- 40×40, в правом верхнем углу на всех слайдах, **кроме первого**.

### Подвал

- Слоган слева — всегда.
- На первом слайде: под логотипом, той же ширины и цвета.
- На остальных — как в Figma.

### Решётка стрелок

- Ставится в пустые места и обязательно заходит за край холста (срез по внешнему краю ряда стрелок).
- На первом слайде — всегда справа сверху.
- Одна любая стрелка решётки — цветная: заменяет серую и сохраняет её направление.
  Не в крайнем к краю ряду.
- Положение — по приоритету:
  1. заполнить пустое место;
  2. верх/низ — по верху/низу ближайшего текстового блока;
  3. выход за холст.
- Мало места — решётки нет.

## Открытая задача

Нужна новая дизайн-система для визуала постов. Прежние попытки через Claude Design
не устроили: не так ставит и убирает элементы фирменной графики. Свои макеты в Figma
«почти нравятся», но в них слишком много текста.
